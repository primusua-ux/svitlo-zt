# Світло: карта відключень Житомирщини

Мобільна сторінка з картою: дотик до будинку показує, чи є світло, з урахуванням графіка відключень, аварій і планових робіт Житомиробленерго.

Адреса сайту: **https://svitloe.net**

- `data/schedule.json` оновлюється автоматично з https://www.ztoe.com.ua/unhooking-search.php
- `data/rem/*.json` база адрес і підчерг
- `data/osm/` координати будинків, © учасники OpenStreetMap (ODbL)

Неофіційний проєкт. Аварійні відключення графік не враховує.
